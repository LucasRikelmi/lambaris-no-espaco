Onde cada coisa fica

Medições e eventos vão para SQLite (ou banco de série temporal). Busca semântica, se usada, fica só nos manuais e checklists e nunca no caminho do alarme.

CREATE TABLE medicao (
  ts INTEGER, tripulante TEXT, sinal TEXT,
  valor REAL, unidade TEXT, origem TEXT
);
CREATE TABLE evento (
  ts INTEGER, tripulante TEXT, regra TEXT,
  severidade TEXT, estado TEXT, detalhe_json TEXT
);
-- manuais e checklists: índice vetorial separado
-- (FAISS ou sqlite-vec), consultado só pela camada 3
